# Evaluation Criteria

**Status:** Architecture / Specification Phase

Evaluation prioritizes correctness and evidence:

1. Requirements and architectural decisions are explicit and traceable.
2. State transitions, idempotency, retries, duplicate delivery, and failure handling are correct.
3. Authentication, authorization, key handling, and redaction are secure.
4. API contracts and migrations are versioned and tested.
5. Local and Kubernetes deployment procedures are reproducible.
6. Telemetry reflects actual behavior and supports diagnosis.
7. Tests cover critical failure paths.
8. Performance claims are reproducible and not invented.
9. UI is professional, information-dense, accessible, and honest about absent data.
10. Complexity is justified by operational or engineering value, not resume keywords.
