# UI/UX Specification

**Status:** Architecture / Specification Phase

The console is a dark-first developer infrastructure product: dense but calm, technical, highly legible, and data-led. It must use real backend data and honest loading, empty, degraded, and error states.

## Primary screens

Login, Overview, Jobs, Job Details, Submit Job, Workers, Queues, AI Models, Metrics, Logs, Traces, API Keys, Audit Logs, and Settings.

## Interaction rules

Polling is the initial update strategy; show last-updated time and stale/degraded indicators. Destructive or irreversible actions require confirmation. Job details emphasize state, timeline, attempts, latency, retry decisions, provider metadata, and validated output. Tables support keyboard navigation, filtering, pagination, and accessible labels.

Do not use fake metrics, testimonials, customer logos, decorative hero gradients, excessive purple, glassmorphism, giant animations, or unlicensed copied designs. Inspiration from listed references is acceptable only where usage rights permit.
